WORKSHOP AI — WAI-109.2
LIVE AVERAGE EFFICIENCY

Changes
- Workshop Control Centre Average Efficiency is now a true live KPI.
- Includes jobs worked on today, including active, paused and completed work.
- Uses authorised/sold hours divided by actual live job-clocked hours.
- Active job timers continue increasing the calculation while technicians work.
- Tile refreshes automatically every 3 seconds while the Control Centre is open.
- Traffic-light status updates live: green 95%+, amber 85–94%, red below 85%.

No changes were made to job workflow, technician clock controls, voice recognition,
Garage Health, invoicing or reporting data.
