Workshop AI WAI-102.1 — Parts Recognition & 240-Day Cost Differences

Prototype enhancements:
- Part number column on estimates, invoices and printed invoices.
- Ordered parts populate part number, description, quantity, cost and sell values into the linked estimate.
- Manual invoice part entry supports recognised part-number suggestions.
- Selecting a recognised number fills known description and latest prices when blank.
- Alerts when the same part number has a different cost from the previous recorded purchase within 240 days.
- Finance Centre Parts Differences report shows all prices paid, minimum, maximum, latest, spread, occurrences and last-seen date.

Keep WAI-102.0 as a backup and test with copied browser data before operational use.
