WORKSHOP AI — WAI-103.0 UNIFIED PRODUCTIVITY ENGINE

Core calculation rules applied across the system:
- Productivity = labour hours sold / actual job-clocked hours x 100
- Efficiency = allocated/sold labour hours / actual job-clocked hours x 100
- Utilisation = actual job-clocked hours / available technician hours x 100

Updated modules:
- Technician dashboard and setup
- Service Manager and Command Centre
- Garage Health
- KPI scorecard
- League tables
- Reports and monthly technician reviews
- Performance Dashboard
- Workshop Intelligence / capacity display

Allocated hours are no longer used as the denominator for productivity.
Only explicit job-clocked time contributes to the productivity denominator.
