Workshop AI — WAI-105.0
Desktop & Tablet Responsive Standardisation

This release keeps the existing interface and application logic while improving screen fit on workshop computers and tablets.

Changes:
- Record Repeat Repair form now uses four columns on large computers, two columns on laptops/landscape tablets and one column in compact tablet views.
- Manager notes and action buttons use the full available width.
- Save and Cancel buttons no longer stretch across or push outside the form.
- Modal windows are constrained to the viewport and scroll internally when required.
- Controls use touch-safe minimum heights for tablet operation.
- Wide tables remain accessible with horizontal scrolling rather than breaking the page.
- Existing customer portal, Workshop Control Centre and authorisation workflows remain unchanged.
