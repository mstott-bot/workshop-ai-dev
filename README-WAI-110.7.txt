Workshop AI WAI-110.7 — Review Centre

Added a working Review Centre without changing existing workshop logic.
- New Review Centre navigation tab.
- Uses completed Workshop AI jobs for the selected month.
- Reads customer phone/email from jobs and CRM where available.
- Search and filter by awaiting/sent review requests.
- Send review requests by Text or Email using the device's SMS/email application.
- Stores sent status against the workshop job so requests are not duplicated accidentally.
- Review Links & Message settings stores Google, Trustpilot, Facebook and one additional review link.
- Standard review message supports {firstName}, {reg} and {links} placeholders.
