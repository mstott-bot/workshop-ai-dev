Workshop AI WAI-108.3 — Continuous Technician Dictation Mode

Changes:
- Voice recording stays active through normal speaking pauses.
- Chrome speech recognition is automatically restarted when the browser ends a segment.
- One continuous transcript is preserved across those restarts.
- Recording finishes only when Stop is pressed or after 25 seconds of complete silence.
- Status shows Listening, Waiting for more speech, Processing, and Ready.
- Duplicate phrase removal, automotive terminology cleanup, and Accept & Add remain enabled.
- Voice cannot change job status, clocking, or labour timers.

Recommended test environment: Google Chrome using Live Server / localhost.
