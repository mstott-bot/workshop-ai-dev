Garage Gurus Workshop — WAI-112.2

Ask Garage Guru suggested-question behaviour update.

Changes:
- Clicking a suggested question now places the full question into the Ask Garage Guru search field.
- The suggestion then uses the same Ask Garage Guru button/submission path as a typed question.
- Pressing Enter in the search field continues to submit the question.
- This keeps the UI ready for a future OpenAI backend: suggested and typed questions will follow the same request path.
- No other Workshop logic changed.
