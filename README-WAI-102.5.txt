Workshop AI WAI-102.5 — Parts Intelligence Dashboard

Changes:
- Exact part number remains the only identifier used for cost comparison.
- High-contrast dark table rows replace the unreadable white report body.
- Summary cards show exact parts monitored, increases, reductions and largest cost range.
- Search and filters for increased, decreased, changed and unchanged exact part numbers.
- View History expands each exact part number into its individual 240-day purchase records.
- History shows date, supplier (where recorded), registration, invoice/source, cost and sell price.
- Different parts with the same generic description are never compared.
