WORKSHOP AI — WAI-107.0
Professional Service Manager UI

This release improves the visual finish of the Service Manager screen while preserving its existing workflow, information, calculations and controls.

Changes
- Existing top-of-page workflow information remains in the same place.
- Service Manager cards use a cleaner professional layout, spacing and typography.
- Job cards have clearer hierarchy, status accents and consistent action buttons.
- Waiting, in-progress, parts, authorisation, quality and completed jobs receive distinct visual accents.
- Move Booking and Start / Continue remain prominent primary actions.
- All existing secondary, authorisation, timeline, invoice and delete actions remain available.
- Future Bookings receive matching visual treatment.
- Desktop and tablet layouts refined.
- No job logic, timer logic, reports, calculations or stored data were changed.
